# COVID-19 Dashboard (Power BI)

An interactive Power BI report exploring COVID-19 data across three pages.

## Pages
| Page | What it shows |
|---|---|
| **Situation Overview** | KPI cards, donut chart, and a filled (choropleth) map of the current situation |
| **Trends & Momentum** | KPI cards, clustered column chart, and scatter chart showing how the pandemic evolved |
| **Ratios & Health Metrics** | KPI cards, treemap, and 100% stacked bar chart comparing key health ratios |

## How to open
1. Install [Power BI Desktop](https://powerbi.microsoft.com/desktop/) (Windows).
2. Download `Covid_19_Dashboard.pbix` from this repo.
3. Double-click to open. Use *Home → Refresh* if you connect your own data source.
